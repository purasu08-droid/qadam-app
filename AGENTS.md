# Инструкции для ИИ-агентов

Подробности — в [README.md](./README.md), [frontend/README.md](./frontend/README.md) и [backend/README.md](./backend/README.md).

- Монорепо на npm workspaces: `frontend/` (Vite + React) и `backend/` (Express + SQLite через `node:sqlite`). Нужен **Node >= 22.13**. Команды из корня: `npm ci`, затем `npm run dev`.
- Фронтенд — http://localhost:5173, API — http://localhost:3001; Vite проксирует `/api`. Проверка `http://localhost:5173/api/health` возвращает `{"ok":true}`.
- В `frontend/src/App.tsx` один серверный SiteProvider расположен выше переключения версий. Десктоп и серверные разделы используют `src/site/SiteApp.tsx`, общий API и авторизацию (`site/api.ts`, `site/state.tsx`).
- По явному решению владельца мобильная версия из ZIP возвращена целиком с отдельным локальным демонстрационным Store: `src/original-mobile/`. 20 исходных файлов защищены SHA-256 в `archive-manifest.json` и тестом. Не редактируй эти экраны/компоненты/store/данные/стили без нового прямого запроса.
- Оболочка и scoped CSS находятся в `src/original-mobile-extras/`; генерация CSS из корня: `node frontend/scripts/scope-original-mobile.mjs`. Дополнительной панели над архивным экраном нет, нижняя навигация сохраняет четыре исходных пункта.
- Согласованные визуальные изменения категорий в `original-mobile-extras/integration.css`: отступ после переключателя 36 px, подъём на 4 px за 0,2 секунды без повышения z-index/тени, четвёртая Events до низа экрана, nav поверх неё. Учитывай reduced motion, safe area, короткую высоту и рамку 400 px при ширине 520–1023 px. Эти изменения не требуют редактировать оригинал.
- Старые корневые `src/screens/`, `src/components/`, `src/data/`, `src/store.tsx`, `src/styles.css` остаются справочной копией. Активная мобильная копия — `src/original-mobile/`; `src/useIsDesktop.ts` определяет границу 1024 px. Не смешивай локальный `qadam.authed` с серверной сессией.
- На телефоне исходные `/`, `/welcome`, `/signin`, `/places`, `/feed`, `/messages`, `/messages/:id`, `/profile`, `/add` обслуживает архив. Серверные `/map`, `/create`, `/chats`, `/chats/:id`, `/projects`, `/p/:id`, `/u/:id` остаются в SiteApp. Серверный мобильный вход — `/account/signin`, профиль — `/account/profile`; на десктопе основные адреса `/signin` и `/profile`.
- Совместимость старых адресов на десктопе реализована в `site/routes.ts`; сохраняй query, hash, id и перевод старого `category` в `kind`. При серверном входе сохраняй безопасный внутренний адрес возврата, включая query/hash; внешние URL и возврат на сам signin отклоняются.
- Публикации бесплатны, без месячных квот, пакетов и оплаты. Создание не должно зависеть от расчёта цены, проверки покрытия или предварительного запроса условий.
- Фильтры серверной карты находятся в URL; `focus` открывает город и точку самой публикации. Leaflet/OpenStreetMap работают без API-ключа. Не вызывай перемещение карты с размерами скрытого контейнера 0×0; сохраняй обработку resize.
- Черновики сохраняются вручную по пользователям: `qadam.site.draft.<userId>`. Перед отправкой дополнительно сохраняется снимок; ключ незавершённой попытки — `qadam.site.publication-attempt.<userId>`. Для событий обязательны дата, начало/окончание, место и координаты.
- Независимая логика повторов — `site/publication-attempt.ts`. `Idempotency-Key` привязан к пользователю и валидированному телу: тот же запрос возвращает прежний результат без дубля; другое тело — 409, удалённый результат — 410. Не меняй ключ после неопределённого ответа. При закрытой/устаревшей попытке сначала предложи проверить «Мои проекты» и явно начать новую отправку; сохраняй личные черновики.
- RU / ҚАЗ / EN и светлая/тёмная темы относятся к серверному интерфейсу; оригинальные мобильные тексты и палитру не подменяй. Ключи настроек — `qadam.site.language` и `qadam.site.theme`, синхронизация между вкладками и раннее применение в `index.html` сохраняются. Не переводи пользовательский контент и не меняй API enum при переводе.
- Для главной сохраняй оба изображения: `public/img/hero-qadam-green.png` и `hero-qadam-light.png`; выбирай по теме, сохраняя размеры и контраст текста. Не перезаписывай исходный тёмный герой.
- База по умолчанию — `backend/data/qadam.db`. В dev пустая база по умолчанию заполняется демо-данными. `npm run seed` удаляет текущие данные и загружает демо-данные заново; не используй его для проверки пользовательской БД.
- Обычный демо-вход — `POST /api/auth/demo`, доступность определяет `GET /api/auth/options`. `ALLOW_DEMO_LOGIN=false` выключает этот вход; не обещай отзыв уже выданных обычных seed-cookie. В production демо по умолчанию выключено, явный `ALLOW_DEMO_LOGIN=true` допускается. Автосид управляется отдельным `SEED_DEMO_DATA`, по умолчанию выключенным в production. Cookie production рассчитаны на HTTPS.
- Серверный чат: один опрос за раз, без опроса скрытой вкладки, защита поздних ответов при смене сессии/пути. Не теряй только что отправленные сообщения и не сбрасывай просмотр истории. Read подтверждает последний реально загруженный message.id только при видимом низе переписки.
- API и схема БД описаны в `backend/README.md`. Новые эндпоинты — в `backend/src/routes/`, валидация — Zod. Принятие/отклонение заявок и загрузка/скачивание вложений пока не реализованы: не описывай их как готовые функции.
- Перед передачей изменений выполни `npm test` и `npm run build` (включает TypeScript). CI запускает установку по lockfile, тесты и сборку; интерфейс дополнительно проверяй в браузере. Указывай только фактически выполненные проверки, без непроверенных количеств тестов.
- Не коммить `backend/data/`, `.env`, `node_modules/`, `dist/`.
